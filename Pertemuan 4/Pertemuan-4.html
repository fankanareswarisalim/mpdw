Proses AR(2)

Model: \(Y_t = \phi_1 Y_{t-1} + \phi_2 Y_{t-2} + e_t\), dengan \(\phi_1 = 0.5\) dan \(\phi_2 = 0.2\).

Membangkitkan Data

Cara Manual

phi1 <- 0.5
phi2 <- 0.2

e2 <- rnorm(n + 100)  # burn-in 100 observasi
Y_ar2_manual <- numeric(n + 100)

for (t in 3:(n + 100)) {
  Y_ar2_manual[t] <- phi1 * Y_ar2_manual[t - 1] + phi2 * Y_ar2_manual[t - 2] + e2[t]
}

Y_ar2_manual <- ts(Y_ar2_manual[-(1:100)])  # buang burn-in

Identifikasi kestasionerary: Proses AR(2) dikatakan stasioner jika akar-akar persamaan karakteristik berada di luar lingkaran satuan (unit circle). Dengan \(\phi_1 = 0.5\) dan \(\phi_2 = 0.2\), dapat diperiksa syarat kestasioneran AR(2): \(\phi_1 + \phi_2 < 1\), \(\phi_2 - \phi_1 < 1\), dan \(|\phi_2| < 1\). Ketiga syarat terpenuhi sehingga proses bersifat stasioner. Hal ini didukung oleh plot ACF yang meluruh (tails off) secara eksponensial/gelombang teredam, sedangkan PACF terputus (cuts off) setelah lag ke-2.

cat("phi1 + phi2 =", phi1 + phi2, "< 1 ?", (phi1 + phi2) < 1, "\n")
## phi1 + phi2 = 0.7 < 1 ? TRUE
cat("phi2 - phi1 =", phi2 - phi1, "< 1 ?", (phi2 - phi1) < 1, "\n")
## phi2 - phi1 = -0.3 < 1 ? TRUE
cat("|phi2| =", abs(phi2), "< 1 ?", abs(phi2) < 1, "\n")
## |phi2| = 0.2 < 1 ? TRUE
